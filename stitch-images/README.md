# VIM Stitch AI Image Library

These 27 images were AI-generated by Google's Stitch tool for the **Kinetic Noir** design concept.
They are hosted at temporary Google URLs — **download and commit them before the URLs expire.**

To download all images at once, run from the repo root:
```bash
bash stitch-images/download-stitch-images.sh
```

Then upload the resulting `stitch-images/` folder contents to GitHub via the web UI.
